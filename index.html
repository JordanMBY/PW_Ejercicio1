Mateo:¿Que son las etiquetas?

Son fragmentos de código que se utilizan para estructurar y dar formato al contenido de una página web, indicando al navegador cómo debe mostrar elementos como texto, imágenes, enlaces y videos

Mateo:¿Que quiere decir http y https?

Jordan: son protocolos de transferencia de datos en la web, pero HTTPS es la versión segura de HTTP

Mateo:¿Que protocolos existen?

HTTP (HyperText Transfer Protocol): Es la base de la web, utilizado para transferir datos entre un navegador y un servidor web. No es seguro, por lo que los datos pueden ser interceptados. HTTPS (HyperText Transfer Protocol Secure): Es la versión segura de HTTP. Utiliza cifrado a través de TLS/SSL para proteger la comunicación, lo que lo hace el estándar para todos los sitios web modernos. DNS (Domain Name System): Traduce nombres de dominio legibles por humanos (como www.ejemplo.com) en direcciones IP numéricas que las computadoras pueden entender. TCP/IP (Transmission Control Protocol/Internet Protocol): Es un conjunto de protocolos que rigen la comunicación en Internet. IP se encarga de direccionar y enrutar los paquetes de datos, mientras que TCP asegura que los datos se entreguen de manera fiable. FTP (File Transfer Protocol): Se utiliza específicamente para transferir archivos entre un cliente y un servidor. SSH (Secure Shell): Permite el acceso remoto seguro a un ordenador, cifrando la conexión y los datos transmitidos.

Mateo:¿Que es un localhost?

Es un término que se refiere a tu propio ordenador, una forma de acceder a él como si fuera un servidor local, sin necesidad de una red externa

Mateo:¿Cual es la estructura para una pagina web?

La estructura básica de una página web se compone de tres partes principales: cabecera (header), cuerpo (body) y pie de página (footer)
